# 恶人模式方程合成辅助工具

一个帮助玩家在游戏「雷霆战机」恶人模式中快速选择最优方程的辅助工具。

## 功能特点

- **方程记录**：记录已获得的方程及其数量
- **进度展示**：可视化展示各流派的合成进度
- **智能推荐**：根据当前可选方程，推荐最优选择以最快达成终极效果
- **数据持久化**：支持保存和加载游戏进度

## 技术栈

- Vue 3 + Vite
- Lucide Vue Next (图标库)
- 响应式设计，支持多设备

## 使用说明

1. **开始新游戏**：点击右上角「新游戏」按钮清空进度
2. **选择方程**：在中间区域点击当前游戏中出现的方程（最多选3个）
3. **查看推荐**：系统会自动分析并推荐最优选择
4. **确认选择**：点击「确认选择」将推荐的方程添加到已获得列表
5. **手动调整**：在右侧已获得列表中可手动增减方程数量

## 推荐算法

系统根据以下优先级推荐方程：
1. **最高优先级**：选择后可合成终极效果
2. **高优先级**：选择后可合成二阶方程
3. **中优先级**：能推进当前进度最快的流派
4. **低优先级**：能开启新流派的基础方程
5. **不推荐**：重复且已满足数量要求的方程
